# curfew

A modular, plugin-based tool for managing kid screentime across the household. A small dockerized core service exposes an HTTP API; plugins enforce policy on different surfaces — Windows PCs, DNS, smart plugs, router ACLs, and more.

In the planning stage. See [docs/PLAN.md](docs/PLAN.md) for scope and roadmap, and [docs/DECISIONS.md](docs/DECISIONS.md) for architectural decisions and tradeoffs.
